# Hamd — Wonderlife & dot

مستودع تطوير وتوثيق ربط إدارة Wonderlife مع dot وWork.

## الأدوار المستهدفة

- ChatGPT: الإشراف ومراجعة النتائج.
- Google Sheets / Agent_Queue: سجل المهام المركزي.
- Work: التنفيذ عبر قناة مدعومة ومصرح بها.
- dot: متابعة المهام والتقارير.
- Agent_Log: تسجيل نتائج التنفيذ وأدلته.
- GitHub / Hamd: حفظ كود التكامل ووثائقه ومراجعة تعديلاته.

## المنجز

- التحقق من قراءة وكتابة ملفات GitHub.
- إضافة [أداة فحص سجلات CSV](tools/audit_queue.py) تعمل محليًا دون اتصال أو تعديل البيانات: تكشف المعرّفات المكررة، الميزانيات غير الصالحة، ونقص النطاق أو مراجع التقارير.
- إضافة [خمسة اختبارات](tests/test_audit_queue.py) اجتازت الفحص أثناء التطوير.
- إضافة [دليل التشغيل وحدود الربط](docs/INTEGRATION.md).

الأداة لا تتصل تلقائيًا بـGoogle Sheets ولا ترسل مهام إلى dot أو Work. نجاح الفحص لا يثبت التنفيذ أو الاعتماد. قناة الإرسال المباشر غير متاحة في جلسة التطوير الحالية؛ الربط التلقائي الكامل لم يُثبت.

## ضوابط العمل

- الحفاظ على المهام والجداول القائمة دون تكرارها.
- عدم إنفاق مبالغ إضافية دون موافقة المستخدم.
- فصل المشروع التجاري عن المشاريع الثقافية.
- عدم حفظ كلمات المرور أو رموز الوصول أو السجلات الخاصة في المستودع العام.

## التحقق من اكتمال الربط

يلزم التحقق من قناة التنفيذ وصلاحياتها، ثم تتبع مهمة اختبار واحدة بمعرّف فريد من إرسالها إلى استلامها وتنفيذها وتسجيل نتيجتها، دون إنشاء جدول جديد. يجب توثيق النتيجة الفعلية قبل إعلان نجاح الربط.
